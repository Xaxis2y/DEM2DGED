Step 5  strip/halo blocking must not create a seam
----------------------------------------------------------------------------
  build_prefiltered_source() processes the raster in horizontal
  strips sized to max_block_bytes, each read with a radius-row
  halo. At the default 256 MB budget a test-sized raster fits in
  ONE block, so the multi-strip path -- the one every real,
  multi-gigabyte source actually takes -- would never be
  exercised. This forces a tiny budget so the same raster is cut
  into many strips, and requires the result to be BIT-IDENTICAL
  to the single-block pass.

Pre-filter: Gaussian sigma=4.500 source px (kernel radius 18), 12 row(s) per block
  [PASS] multi-strip output is bit-identical to the single-block pass  -- max |difference| = 0.000e+00 m
  [PASS] void footprint identical under both blocking schemes

The benefit tracks terrain roughness, and reverses on very
smooth ground -- which is exactly why -prefilter defaults to
'none'. Use it on high-relief sources being downsampled, and
verify on YOUR data with dem2dged_validate.py before shipping a
delivery made with it.
